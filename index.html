how it works

Conversion is two steps. First the input is split into a list of words. Boundaries are: any non-alphanumeric run (space, dash, underscore, dot, slash), a lowercase letter followed by uppercase (helloWorld → hello | World), and a run of capitals followed by a capital plus lowercase (HTMLParser → HTML | Parser). Digits stick to the previous word.

Then those words get re-joined in whichever style you want. So HTMLParser_v2 and html-parser-v2 both end up as the same word list, and convert to the same output.

No build step, one file each. Open index.html.
